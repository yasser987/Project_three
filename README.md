# Yasser Frontend Portfolio

A responsive personal portfolio website presenting frontend projects, technical skills, services, experience, and contact information through a modern multi-section interface.

## Features

- Responsive layouts for mobile, tablet, and desktop
- Semantic HTML structure
- Modern CSS Grid and Flexbox layouts
- Reusable components and design variables
- Accessible navigation and interactive elements
- Project, skills, services, and contact sections

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Font Awesome

## Quality Standards

The project is reviewed for responsive behaviour, accessibility, semantic structure, SEO, performance, maintainability, and cross-browser usability.
